# AI PM 学院

给「想做 AI 产品经理，并最终能独立交付一个 AI 功能」的人准备的学习台。纯静态、零依赖、零构建，双击 `index.html` 就能用。

## 它做什么

从最基础的 **LLM** 一路讲到 **Loop**、**Skill**、**Eval**，再到 **Rerank、模型选型、自动化边界、AI 交互设计、风险分级、灰度与回滚** —— 61 个概念、30 节课、6 个阶段。每个词条都配了生活化类比、真实例子、PM 决策视角、常见误区和小测验。

六个阶段：`建立直觉` → `让它稳定干活` → `Agent 是怎么转起来的` → `从 Demo 到产品` → `进阶实战` → `独立交付`。最后一阶不再堆技术名词，而是把前面的能力收束成完整产品决策：选对问题、拆清任务、划定人机边界、设计失败恢复、建立成效指标，再用灰度和回滚安全上线。

五件事是它的核心：

1. **讲人话** —— 一句话 → 打个比方 → 展开说说 → 举个例子 → PM 视角 → 容易踩的坑 → 随机变式小测
2. **能追问** —— 右侧 AI 栏，配任意 OpenAI 兼容端点即可真对话；没配也能用，内置离线知识库会命中术语作答
3. **记得住你** —— 长期记忆 + 自适应
4. **能实战** —— 12 个来自课程材料的功能级练习，覆盖需求、Prompt、工作流、Agent、产品化和交付
5. **能测评** —— 从 94 道精选 AI PM 面试题中抽取 12 道客观题和 8 道开放题，按 8 个维度评分并生成补弱计划

## 实战练习与面试测评

- **12 个功能级练习**：模糊需求转任务、事实与假设、MVP 切片、工程级 Prompt、工作流拆解、确认门禁、Agent 四层架构、RAG/SQL/Function/MCP 选型、订单查询 Chatflow、风险工作流、Demo 产品化、正式研发交接
- **练习闭环**：写自己的方案 → 对照检查点 → 做关键判断 → 查看参考拆解 → 四档自评
- **94 道精选面试题**：从用户提供的题库中去重、去时效化并重写；每次抽取 20 道，题序和 3~5 个选项顺序随机
- **混合评分**：12 道客观题自动评分，8 道开放题按关键点量表自评；在线模型只补充点评，不改变稳定分数
- **知识点变式题**：61 个概念各有 3 种问法；答对后仍会间隔复测，但优先换题，不重复背答案
- **今日学习答题流**：点击开始后采用一题一屏，答完看解析再进下一题；完成后生成 0~100 的今日掌握度
- **评分计划**：按薄弱维度自动组合概念复习和实战任务；高分用户进入复杂案例与方案表达冲刺，完成后可重新测评

## 长期记忆与自适应

- **掌握度**：`答对×1.2 − 答错×1.4 − 标记不懂×2 + 标记懂了×1.6`，0~5 分
- **水平画像**：四维打分（概念广度 / 掌握深度 / 持续度 / 主动度）合成 0~100 分等级，带趋势
- **习惯画像**：常学时段、单次时长、完成率、偏好哪种追问方式
- **自适应出口**：
  - 某类内容判定吃力 → 打开该类术语自动进「小白模式」（先讲为什么需要它、多用类比、补先修知识）
  - 注意力预算：深夜或碎片时段自动缩短内容、只排轻量复习
  - 复习队列按「越不熟 + 越久没看 + 卡得越多」排序
  - 记忆摘要注入 LLM system prompt，AI 知道你卡在哪、习惯怎么听

## 学习计划

不是每次现算的推荐，是一份**会推进的真课表**：

- 30 节课 + 6 个阶段检查点，固定顺序
- 每天生成一份清单并**按天冻结**，做几项就是几项
- 完成判定是真判定：读完（累计 25 秒）+ 答题或表态，只点开不算
- 昨天没做完的项自动顺延到今天最前面

## 数据存在哪

全部在浏览器 `localStorage`，不上传任何服务器。练习答案、面试得分和评分学习计划会并入原有记忆数据。可选开启「文件同步」：把记忆写进你自己指定的文件，放进 iCloud / OneDrive / 坚果云即可跨设备同步。可导出 / 导入 / 清空。

## 本地跑

```bash
python3 -m http.server 8777
# 打开 http://127.0.0.1:8777
```

直接双击 `index.html` 也能用，只是部分模型厂商会对 `file://` 来源的跨域请求有限制。

## 接真实大模型

我的学习 → 设置与记忆 → 启用在线大模型 → 填 Base URL / Key / 模型名 → 测试连接。支持 OpenAI、DeepSeek、Moonshot、通义，以及本地 Ollama 等任何 OpenAI 兼容端点。
