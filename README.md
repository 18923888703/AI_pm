# AI PM 学院

给「想做 AI 产品经理，并最终能独立交付一个 AI 功能」的人准备的学习台。前端无需构建，本机学习可直接打开；可选的手机同步使用 Netlify Functions 与 Blobs。

## 它做什么

从最基础的 **LLM** 一路讲到 **Loop**、**Skill**、**Eval**，再到 **Rerank、长期记忆、模型选型、自动化边界、AI 交互设计、风险分级、灰度与回滚** —— 61 个主课概念、31 个延伸概念、30 节课、6 个阶段。每个词条都配了生活化类比、真实例子、PM 决策视角、常见误区和小测验。

六个阶段：`建立直觉` → `让它稳定干活` → `Agent 是怎么转起来的` → `从 Demo 到产品` → `进阶实战` → `独立交付`。最后一阶不再堆技术名词，而是把前面的能力收束成完整产品决策：选对问题、拆清任务、划定人机边界、设计失败恢复、建立成效指标，再用灰度和回滚安全上线。

五件事是它的核心：

1. **讲人话** —— 一句话 → 打个比方 → 展开说说 → 举个例子 → PM 视角 → 容易踩的坑 → 随机变式小测
2. **能追问** —— 右侧 AI 栏沿用已配置的 OpenAI 兼容供应商；每轮术语追问同一次调用返回回答与学习信号，未配置时仍可离线讲解
3. **记得住你** —— 显式学习目标、错题证据、错因线索、跨日复测与导师画像；本地保存，可选用配对码在手机和电脑间加密同步
4. **能实战** —— 16 个来自课程材料的练习，覆盖需求、Prompt、工作流、Agent、长期记忆、产品化、交付和求职证据
5. **能测评** —— 从 152 道结构化 AI PM 面试题中抽取 12 道客观题和 8 道开放题，按 8 个维度评分并生成补弱计划

## 实战练习与面试测评

- **16 个实战练习**：在原有任务上新增 AI PRD/UE、Eval 回归、简历证据与学习型 Agent 长期记忆设计
- **练习闭环**：先看两个相邻案例 → 独立写方案（不提前展示参考）→ 提交后看逐项分析 → 对照检查点与参考拆解 → 自评。已配置在线模型时，点评会引用答案原文并提出具体修改；未配置时提供明确标注的本地结构检查。
- **152 道结构化面试题**：在原有 150 题上新增两道长期记忆场景题；每次仍抽取 20 道
- **混合评分**：12 道客观题自动评分，8 道开放题按关键点量表自评；在线模型只补充点评，不改变稳定分数
- **连续测评**：面试测评中途刷新或退出会作废本轮答案，返回后重新抽题、重新计分，未完成记录不污染历史统计
- **知识点变式题**：92 个概念各有至少 5 种问法；新增长期记忆的 21 道人工编写题，到期复测优先更换原题与考查角度
- **精简但不送分的选项**：学习、面试客观题与实战判断题采用同一场景下的近似判断；不再把无关术语和过长段落拼进题目，选项顺序仍随机，稳定答案 ID 与历史成绩不变
- **错题详解**：展示选择的具体问题、正确判断依据、生活类比、分步原理、真实应用与易混概念；面试客观题按稳定选项 ID 匹配逐项解释
- **随题问 AI**：知识点与专题可直接追问；每日学习、复测、面试题和实战任务会自动带入当前题目。提交前给推理线索，提交后结合你的答案完整解释；答前与答后对话隔离。沿用设置中已启用的模型供应商，未配置时明确显示离线提示。
- **今日学习答题流**：点击开始后采用一题一屏，答完看解析再进下一题；完成后生成 0~100 的今日答对率
- **答题后诊断与巩固**：做题中只显示完成进度；完成后可逐题展开错题解析并重新理解知识点。每轮为当天原错题知识点另抽两道变式，完成两轮后才显示汇总巩固正确率，首次成绩保持独立
- **到期复测与长期掌握度**：今日答对率只反映当天题目；答错约 1 天、初次答对约 2 天后复测，连续跨日答对逐步延长间隔，两个不同日期的到期复测答对才计入长期掌握
- **首页互斥学习状态**：未完成时展示立即／继续学习；有错题但尚未巩固时展示错题入口；完成第一轮巩固后首页回到进度与数据，报告内继续第二轮，完成两轮后显示巩固正确率
- **可视化知识脑图**：每个知识点都有“它是什么 / 什么时候用 / 典型场景”，并以当前概念为根节点连接先修、协同、延伸及专题阅读
- **专题知识库**：34 个结构化专题，支持搜索、课程关联与移动端阅读
- **独立知识库入口**：桌面端左侧导航可直接进入专题知识库，专题详情保持入口高亮
- **知识库全景脑图**：以 AI PM 能力体系为中心，双向连接 8 类能力与 34 个专题，支持横向浏览和节点直达
- **Eval 工程体系**：新增评估集、评估维度、组合评分、自动执行、评估报告、CI 发布门禁与反馈闭环
- **评分计划**：按薄弱维度自动组合概念复习和实战任务；高分用户进入复杂案例与方案表达冲刺，完成后可重新测评
- **延伸知识**：31 个补充概念独立放在学习路径末尾，可搜索、追问、测验和复习；不改动既有 61 个主课概念的完成进度
- **三份新课件**：PRD 与 UE 的行为契约、框架选型、空多错慢；Eval 的四态判定、基线快照、回归决策；求职的岗位映射、项目证据、转岗资产。每个知识点注明资料与页码，课件原文不公开，示例数字不视为通用门槛，个人经历与项目成果要求如实可核验
- **长期记忆课件**：区分工作记忆与长期记忆、三层证据、写入—检索—更新—遗忘、冲突与时间边界、个性化和错因复测；原课件不上传公开仓库

## 长期记忆与自适应

- **掌握度**：`答对×1.2 − 答错×1.4 − 标记不懂×2 + 标记懂了×1.6`，0~5 分
- **水平画像**：四维打分（概念广度 / 掌握深度 / 持续度 / 主动度）合成 0~100 分等级，带趋势
- **习惯画像**：常学时段、单次时长、完成率、偏好哪种追问方式
- **可核对的导师画像**：困难类型限定为 7 类、有效讲法限定为 6 类；答题和追问形成逐条可见信号，累计 6 条后生成简短归纳，旧信号按时间降低权重
- **按画像重讲**：术语页可请求新的解释；同一知识点和画像直接复用缓存，也可手动重新生成；未配置模型时使用课程材料整理
- **规则推荐**：卡住的概念优先，再考虑先修知识、薄弱类别、最近学过的关联概念与难度；展示推荐理由，不改动当天冻结的主课计划
- **对话管理**：知识点对话分开保存、可单独清空；学习信号保留供画像核对，全部记忆仍可整体导出或清空
- **错题证据链**：错题本保留题目、错误选择、正解、来源和时间；重复出现才形成“错因线索”，可回到原题核对
- **长期校准**：自评“已掌握”不会直接计入长期掌握；不同日期的到期变式复测通过后才确认，答错会缩短间隔
- **显式画像**：学习目标、背景与每日时间由用户填写并可修改，不从单次错题推断长期能力缺陷
- **自适应出口**：
  - 某类内容判定吃力 → 打开该类术语自动进「小白模式」（先讲为什么需要它、多用类比、补先修知识）
  - 注意力预算：深夜或碎片时段自动缩短内容、只排轻量复习
  - 复习队列按「越不熟 + 越久没看 + 卡得越多」排序
  - 记忆摘要注入 LLM system prompt，AI 知道你卡在哪、习惯怎么听

## 学习计划

不是每次现算的推荐，是一份**会推进的真课表**：

- 30 节课 + 6 个阶段检查点，固定顺序
- 每天生成一份清单并**按天冻结**，做几项就是几项
- 完成判定是真判定：读完（累计 25 秒）+ 答题或表态，只点开不算
- 昨天没做完的项自动顺延到今天最前面

## 数据存在哪

学习记录、错题、画像、重讲缓存和模型配置先保存在浏览器 `localStorage`。公开 HTTPS 站点可用私下提供的随机配对码开启手机同步：学习数据在浏览器内用 AES-GCM 加密，Netlify Blobs 只保存密文；服务端只允许预配置的一个同步房间，并使用 ETag 避免旧设备覆盖新版本。配对码保存在各自设备上，不进入公开仓库；丢失全部设备和配对码后无法解密云端记录。模型 API Key 留在各设备本地，不同步。桌面浏览器仍可选文件同步或导出 JSON 备份。启用在线模型后，相关内容会发送给用户所配置的模型供应商；未启用时不会调用该供应商。

## 本地跑

```bash
python3 -m http.server 8777
# 打开 http://127.0.0.1:8777
```

直接双击 `index.html` 仍能本机学习；`file://` 不能使用 HTTPS 云同步，且部分模型厂商会限制跨域请求。

## 接真实大模型

我的学习 → 设置与记忆 → 启用在线大模型 → 填 Base URL / Key / 模型名 → 测试连接。沿用原有供应商配置，支持 OpenAI 兼容端点。导师结构化输出优先尝试 JSON Schema，供应商不支持时降级到 JSON Object，再降级到普通文本提示，并记住本次可用模式。

新增导师能力参考了用户提供的 [agentpm 公开仓库](https://github.com/gaoweiblue-source/agentpm) 的功能设计，按本站已有架构独立实现；原仓库使用的本机 Python/SQLite 服务没有作为线上后端部署。

云端同步部署时需安装 `@netlify/blobs`，并在 Netlify 环境变量中配置 `AIPM_SYNC_ROOM_ID` 与 `AIPM_SYNC_AUTH_HASH`；仓库只保留算法和函数，不保存配对码或可解密密钥。直接部署公开仓库但未配置这两项时，云同步接口会拒绝服务，本机学习不受影响。
